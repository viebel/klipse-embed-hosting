interactive & shareable code snippets

Docs

  1. Pick a language

    Choose it from the menu above the editor: JavaScript, Python, Ruby, Clojure, Go, C++, SQL and more.

  2. Write code

    The code runs in your browser as you type and the result shows up right below the editor. Nothing is sent to a server.

  3. Combine snippets

    adds another snippet to the page, in any language. removes one.

  4. Share a link

    copies a link to your snippets. Whoever opens it can run and edit the code.

  5. Embed anywhere

    gives you an iframe to paste in a blog post, a doc or a slide. Set its width and height, then copy the code.

  6. Preview

    opens your snippets as your readers will see them.

Your code is stored in the link itself: no account, nothing saved on our side. Long code makes long links, which some apps may truncate.
